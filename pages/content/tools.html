Work from the terminal

The cyclonedds
command-line tool

Inspect your DDS system without leaving your development environment.

List discovered entities and their QoS, identify applications, inspect topic types or subscribe to live data. The command-line tool is included with the Cyclone DDS Python package.

Install the Python package python -m pip install cyclonedds Installation details →
Explore the command-line reference →
View source on GitHub
A few useful commands cyclonedds
# Discover DDS entities and their QoS
$ cyclonedds ls

# List discovered applications
$ cyclonedds ps

# Inspect the type of a topic
$ cyclonedds typeof <topic>

# Subscribe to samples on a topic
$ cyclonedds subscribe <topic>

# Show commands and options
$ cyclonedds --help

Replace <topic> with a topic name from your DDS system.
